# Leonardo Lopes | Eleve-se

Esse prompt eu dividiria em duas etapas. O Lovable possui limite de contexto e tende a degradar a qualidade quando recebe um PRD muito extenso em uma única solicitação. O ideal é usar um Prompt Master seguido por prompts incrementais. Porém, se o objetivo é iniciar o projeto criando toda a estrutura navegável, este seria o prompt inicial.



⸻



PROMPT MASTER — LEONARDO OS v1.0



Você é um Product Designer Sênior, UX Researcher, UX Writer, UI Designer, Motion Designer, Arquiteto Front-end e Especialista em Produtos SaaS premiados internacionalmente.



Sua missão é criar um produto digital premium chamado Leonardo OS, utilizando as melhores práticas de Design System, UX, UI, Motion Design e Arquitetura Front-end.



O projeto deve possuir qualidade equivalente aos melhores cases publicados no Behance, Figma Community, Awwwards e Landbook.



Não produza um site comum.



Projete um produto digital de nível enterprise.



Toda decisão deve priorizar clareza, sofisticação, usabilidade, consistência visual, acessibilidade, performance e escalabilidade.
